# Админка Bashir&Co — подключение

Админка написана. Осталось подключить базу (Neon) и хранилище фото
(Vercel Blob). Занимает ~15 минут.

**Важно:** пока база не подключена, сайт работает как обычно — показывает
12 товаров из кода. Ничего не сломается, если отложить настройку.

---

## Шаг 0. Сначала выложите сайт

Если сайта ещё нет на Vercel — сделайте это по `DEPLOY.md`. База
подключается уже к существующему проекту.

## Шаг 1. Создайте базу данных (Neon)

1. На **vercel.com** откройте проект `bashir-co`
2. Вкладка **Storage** → **Create Database**
3. Выберите **Neon** (Serverless Postgres) → **Continue**
4. Регион — ближе к вам (например Frankfurt) → **Create**
5. Нажмите **Connect** к проекту

Vercel сам добавит переменную `DATABASE_URL` — копировать ничего не надо.

**Тариф:** бесплатный. 0.5 ГБ хранилища — это десятки тысяч товаров
(в базе только текст, фото хранятся отдельно).

## Шаг 2. Создайте хранилище для фото (Blob)

1. Там же: **Storage** → **Create Database** → **Blob** → **Create**
2. **Connect** к проекту

Vercel добавит `BLOB_READ_WRITE_TOKEN`. Бесплатно до 1 ГБ фото.

## Шаг 3. Логин, пароль и секрет

1. **Settings** → **Environment Variables**
2. Добавьте три переменные:

| Название | Значение |
|---|---|
| `ADMIN_EMAIL` | ваш email (им будете входить) |
| `ADMIN_PASSWORD` | придумайте пароль, минимум 10 символов |
| `ADMIN_SECRET` | случайная строка (см. ниже) |

**Как сгенерировать `ADMIN_SECRET`** — в терминале:

    openssl rand -hex 32

Скопируйте результат. Это ключ подписи сессии — без него вход не
заработает.

3. Отметьте все три окружения: Production, Preview, Development.

## Шаг 4. Передеплойте

    vercel --prod

Переменные подхватываются только при новом деплое.

---

## Как пользоваться

1. Откройте `https://ваш-сайт.vercel.app/admin`
2. Войдите (email и пароль из шага 3)
3. При первом входе база пустая → нажмите **«Импортировать 12 товаров»**
4. Дальше: **+ Добавить товар**, **Изменить**, **Удалить**

### Поля товара

- **Фото** — загрузка с компьютера (JPG/PNG, до 8 МБ)
- **Название RU / EN** — обязательны оба (сайт двуязычный)
- **Категория** — часы, одежда, обувь, сумки, украшения, аксессуары
- **Цена RU / EN** — текстом: «Цена по запросу» или «12 500 000 ₸»
- **Описание RU / EN** — необязательно
- **Порядок** — меньше число, выше в списке
- **Показывать на сайте** — снять галочку, чтобы временно скрыть

Изменения появляются на сайте **сразу**, передеплой не нужен.

## Про кэширование (важно понимать)

Каталог кэшируется на 5 минут, чтобы:
- не расходовать лимиты базы на каждого посетителя
- посетитель не ждал, пока «спящая» база Neon просыпается

При изменении товара в админке кэш сбрасывается автоматически — вы
увидите правку сразу. А вот случайный посетитель, открывший каталог за
секунду до вашей правки, может ещё несколько минут видеть старую версию.
Это нормально и специально так сделано.

## Если что-то пошло не так

**«База данных недоступна»**
→ Проверьте, что Neon подключён (Storage → Connect) и был новый деплой
после этого.

**Не пускает по паролю**
→ Проверьте `ADMIN_EMAIL` / `ADMIN_PASSWORD`. Пользователь создаётся при
первом входе; если потом поменять пароль в переменных, старый останется
в базе. Чтобы сбросить — удалите строку из таблицы `admin_users`
(Storage → Neon → откройте базу → SQL Editor).

**«Хранилище фото не настроено»**
→ Не подключён Blob (шаг 2) или не было деплоя после подключения.

**В админке одни товары, на сайте другие**
→ Значит сайт не видит базу и показывает запасной набор из кода (это
защита от падения). Проверьте `DATABASE_URL` и передеплойте.

## Стоимость

Всё бесплатно на старте:
- **Neon**: 0.5 ГБ + 100 CU-часов/мес — хватает надолго
- **Blob**: 1 ГБ фото

При серьёзном трафике (десятки тысяч посетителей) возможно потребуется
платный тариф (~$10/мес). Кэширование сильно оттягивает этот момент.
