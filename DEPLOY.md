# Bashir&Co — деплой на Vercel (загрузкой папки)

Проект готов к деплою без правок. Ниже — самый простой путь: загрузка
папки напрямую в Vercel (без GitHub).

## Шаг 1. Аккаунт
1. Откройте https://vercel.com → **Sign Up** (можно через Google — бесплатно).

## Шаг 2. Установите Vercel CLI (один раз)
Нужен установленный Node.js 20+ (nodejs.org).
В терминале:

    npm install -g vercel

## Шаг 3. Задеплойте папку
1. Распакуйте архив, зайдите в папку проекта:

       cd путь/к/bashir-co

2. Запустите:

       vercel

3. CLI задаст несколько вопросов — отвечайте так:
   - Set up and deploy? → **Y**
   - Which scope? → выберите свой аккаунт
   - Link to existing project? → **N**
   - Project name? → например `bashir-co` (или Enter)
   - In which directory is your code? → **./** (Enter)
   - Override settings? → **N**

4. Vercel сам определит Next.js, соберёт и через ~1–2 минуты выдаст
   ссылку вида `https://bashir-co-xxxx.vercel.app`.

5. Для «боевой» ссылки (production) выполните:

       vercel --prod

   Получите чистую ссылку `https://bashir-co.vercel.app` — её и
   показывайте заказчику.

## Альтернатива без CLI (через браузер)
Если не хочется ставить CLI:
1. Залейте проект на GitHub (создайте репозиторий, загрузите файлы).
2. На vercel.com → **Add New → Project → Import** из GitHub.
3. Vercel определит Next.js автоматически → **Deploy**.

## Важно перед показом (напоминания)
- Контакты в `lib/contacts.ts` — заглушки (email/telegram/телефон).
  Замените на реальные до показа, если будете кликать по ним.
- Фото: реальные только в герое и категории «Часы». Остальные слоты —
  плейсхолдеры. Кладите свои фото в `public/images/` по именам из
  `public/images/README.md` — подхватятся автоматически.
- Тексты (названия позиций, слоганы) — черновые, замените на реальные.

## Технические детали (на случай вопросов)
- Framework: Next.js 16 (App Router) — Vercel определяет сам.
- Build command: `next build` (по умолчанию).
- Node version: 20+ (Vercel по умолчанию).
- Никаких переменных окружения не требуется.
- Шрифт Cormorant и все изображения — в `public/`, отдаются статикой.
